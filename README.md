## MeuCineClube

Projeto desenvolvido em React para a disciplina de Desenvolvimento Web.

O sistema possui:
- Login 
- Tema claro/escuro
- Rotas protegidas
- Lista de filmes
- Navegação entre páginas sem recarregar

## Tecnologias

- React
- Vite
- React Router DOM
- Context API
- CSS

## Como executar

```bash
npm install
npm run dev
```
